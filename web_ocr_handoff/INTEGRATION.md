# On-device OCR handoff

`OnDeviceLabelExtractor` is a browser-only, offline-first PP-OCRv3 mobile pipeline. It preserves the established extraction response exactly: `image_id`, `product_category`, `extracted_fields`, and `raw_ocr_text`. It intentionally does **not** add `needs_review`; the Group 2 API already maps low field confidence to its own review status.

## Assets and page dependencies

Copy the ONNX detector, recognizer, and `en_dict.txt` generated by `web_ocr_benchmark/scripts/download-and-convert-models.sh` into the PWA's public `models/` directory. Load OpenCV.js and ONNX Runtime Web before importing the module:

```html
<script async src="https://docs.opencv.org/4.x/opencv.js"></script>
<script src="https://cdn.jsdelivr.net/npm/onnxruntime-web/dist/ort.min.js"></script>
<link rel="stylesheet" href="/capture-guide.css">
<div class="label-camera-guide"><video id="camera" autoplay playsinline></video></div>
```

Pin and self-host these two third-party scripts before the final PWA build so initial loading is cacheable/offline. Models are cached after the browser's first successful load.

## File/camera scan

```js
import { OnDeviceLabelExtractor, CaptureQualityError } from "/on-device-extractor.js";

const extractor = new OnDeviceLabelExtractor({
  detModelUrl: "/models/en_PP-OCRv3_det.onnx",
  recModelUrl: "/models/en_PP-OCRv3_rec.onnx",
  dictionaryUrl: "/models/en_dict.txt",
  confidenceThreshold: 0.5,
  // Keep absent until the team deploys a vision /extract endpoint:
  fallbackUrl: "https://vision.example/api/extract",
});
await extractor.load();

try {
  const scan = await extractor.extractFromFile(fileInput.files[0], {
    imageId: crypto.randomUUID(), productCategory: "cosmetics",
    onFallback: ({ state }) => console.debug("optional server upgrade", state),
  });
  // scan is directly safe to POST to Group 2:
  await fetch("/api/v1/compliance/check", { method: "POST", headers: { "content-type": "application/json" }, body: JSON.stringify(scan) });
} catch (error) {
  if (error instanceof CaptureQualityError && error.code === "GLARE_DETECTED") {
    showMessage("Glare detected—tilt the package slightly and scan again.");
  } else throw error;
}
```

For live camera capture, call `const canvas = await extractor.captureBestFrame(videoElement)` and then `extractFromCanvas(canvas, options)`. It samples three frames about 180 ms apart and retains the sharpest using variance of Laplacian.

## Behavior and limitations

- The OCR detector finds text regions, then applies a four-point perspective crop to each before recognition. CLAHE improves local contrast; glare is rejected when a bright low-saturation region covers more than 2.5% of the frame.
- Declarations below the configured `confidenceThreshold` (default `0.5`) are absent in the returned schema, matching the server. Below average present-field confidence `0.5`, the module silently calls the configured vision endpoint only if online. A successful fallback replaces the entire on-device result. A timeout/failure leaves the offline result untouched.
- `fallbackUrl` is intentionally configurable: the shared backend currently provides `/api/v1/compliance/check`, not a vision `/extract` service.
- Mild perspective is addressed; curved wraparound labels, strong glare, and adversarial/rotated captures remain known limitations.
